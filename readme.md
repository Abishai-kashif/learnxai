## **Overview**
LearnXai is an AI-powered learning companion designed to revolutionize how students learn and how educators assess progress. By combining **personalized study paths**, **dynamic quizzes**, and a **one-click quiz generation tool**, LearnXai bridges the gap between passive learning and active mastery.

Built for **students**, **teachers**, and **organizations**, LearnXai adapts to individual learning styles, automates assessment creation, and provides data-driven insights to optimize study efficiency.

---

## **Key Features**

| Feature                     | Benefit                                                                 |
|-----------------------------|-------------------------------------------------------------------------|
| **Personalized Study Paths** | AI tailors content to your strengths, weaknesses, and learning pace.   |
| **Adaptive Quizzes**         | Reinforce knowledge with auto-generated quizzes that evolve with you.  |
| **Quiz Automation Tool**    | Generate quizzes instantly from **web links, raw text, or PDFs**.      |
| **Multi-Format Input**      | Supports **URLs, documents, and manual text** for flexible quiz creation. |
| **Progress Analytics**      | Track performance trends and focus areas with visual dashboards.       |
| **Collaborative Learning**  | Share study paths and quizzes with peers or classes.                   |
